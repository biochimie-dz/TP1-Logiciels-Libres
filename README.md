# TP1-Logiciels-Libres
Spécialité : Biochimie
Étapes
Créer un compte GitHub.
Installer Git ou GitHub Desktop sur un ordinateur.
Créer un dépôt (repository) et le partager avec une collègue.
Objectif : Découvrir les logiciels libres et Open Source et apprendre à utiliser Git et GitHub pour partager des fichiers et des résultats.
Outil utilisé : GitHub
